# Manikineko Phone

**A privacy-first, Google-free phone you can actually own.**

Manikineko Phone is a phone operating system with its own launcher, first-run setup, signed app store and a hardened SELinux policy. No Google account, no tracking, no analytics. It is not tied to one brand or one phone: the first supported device is the Samsung Galaxy Core 2 (SM-G355HN), more devices will follow.

## Download

The ROM is in **[Releases](../../releases)**: `manikineko-phone-1.8-kanas3gnfc.zip` for the Samsung Galaxy Core 2 (`kanas3gnfc`).

SHA-256: `53b113f62e3c9fa27024d09d1dbf23ec661ee6674989b92142185cc2f5b970b4`

## Install

This wipes user data and needs the TWRP 3.1.1 recovery for this device. Back up first. In TWRP wipe cache, dalvik and data, then install the zip. The first boot restarts once by itself and then the setup starts.

## Notice

The zip contains LineageOS 13 (Apache-2.0 / GPL-2.0), the Samsung 3.10.17 kernel (GPL-2.0) and Samsung proprietary vendor files from the stock firmware. Flashing is at your own risk. Manikineko Phone is an independent project and is not affiliated with Samsung, Google or the LineageOS project.
